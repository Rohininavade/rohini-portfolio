# Rohini Navade | Portfolio

This is the personal portfolio website for Rohini Navade, a Java Backend Developer. The site showcases her experience, projects, technical skills, achievements, and contact information.

## Overview

The portfolio is built as a responsive single-page website using:
- HTML
- CSS
- JavaScript
- Font Awesome icons
- Google Fonts

## Project Structure

```text
rohini-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── other static assets if added later
```

## Included Sections

- Hero section with Java backend branding and animated typing effect
- About section with experience summary and stack
- Professional experience timeline
- Project showcase
- Skills/toolkit section
- Learning and achievements sections
- Contact section with social links
- Responsive navigation and reveal animations

## Resume

Place the final resume PDF in:

```text
assets/Rohini_Navade_Resume.pdf
```

The hero section and download button link to this file.

## Run Locally

You can preview the portfolio in a browser by opening `index.html` directly, or by serving it locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages Deployment

To deploy this portfolio on GitHub Pages:

1. Push the project to a GitHub repository.
2. Go to the repository settings.
3. Open Pages.
4. Select the branch and root folder.
5. Save the deployment.

Example live URL:

```text
https://Rohininavade.github.io/
```
